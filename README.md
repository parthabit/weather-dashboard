# 🌤️ Smart Weather Dashboard

A beautiful, real-time weather app with AI-powered insights and advanced features.

## ✨ Features

- 🔍 **Search Cities** - Find weather for any location
- 📍 **Auto-Detect Location** - Get weather for your current location on load
- 🌡️ **Temperature Toggle** - Switch between °C and °F
- 🌙 **Dark Mode** - Easy on the eyes at night
- 📊 **Weather Charts** - 24-hour temperature, humidity, and wind trends
- ⚠️ **Smart Alerts** - Warnings for extreme weather
- 💨 **Air Quality Index** - Real-time AQI with health advice
- 🌈 **Dynamic Themes** - 6 beautiful weather-based themes
- 💾 **Search History** - Quick access to previous searches
- ⏰ **Hourly & 5-Day Forecast** - Detailed weather predictions
- 💡 **AI Assistant** - Smart weather tips and recommendations

## 🔧 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Python Flask
- **Charts:** Chart.js
- **API:** OpenWeatherMap
- **Hosting:** Render

## 📱 Works On

- Desktop ✓
- Tablet ✓
- Mobile ✓

## 🎯 How It Works

1. **Auto-Detection:** Site detects your location on load
2. **Real-Time Data:** Fetches current weather from OpenWeatherMap API
3. **Smart Display:** Shows weather with theme matching conditions
4. **Interactive Charts:** Beautiful 24-hour trend visualizations
5. **Instant Alerts:** Warns you about extreme conditions

## 🌐 Deploy Yourself

```bash
git clone https://github.com/parthabit/weather-dashboard
cd weather-dashboard
pip install -r requirements.txt
python app.py
```
